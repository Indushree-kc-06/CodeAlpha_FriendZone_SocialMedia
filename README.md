# FriendZone - Social Media Platform

## Overview

FriendZone is a social media platform developed using Django as part of the CodeAlpha Full Stack Development Internship.

The platform enables users to create profiles, share posts, upload images, interact through likes and comments, follow other users, and discover new connections.

## Features

### Authentication

* User Registration
* User Login & Logout

### User Profiles

* Profile Creation
* Profile Photo Upload
* Edit Profile

### Social Features

* Create Posts
* Edit Posts
* Delete Posts
* Upload Images
* Like & Unlike Posts
* Comment System
* Delete Own Comments

### Networking

* Follow / Unfollow Users
* Followers List
* Following List
* User Search

### UI Features

* Instagram-inspired Feed
* Responsive Design
* Profile Gallery Grid
* Modern Navigation Bar

## Tech Stack

* Python
* Django
* HTML5
* CSS3
* Bootstrap 5
* JavaScript
* SQLite3

## Installation

```bash
pip install -r requirements.txt
python manage.py makemigrations
python manage.py migrate
python manage.py runserver
```
